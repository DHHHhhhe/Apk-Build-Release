### 修复

- **输出目录里的旧包能真正被替换了**：上一版改成「覆盖同名产物」后，工程如果在 Gradle 里把构建时间戳拼进文件名（每次构建的文件名都不同），覆盖就永远不生效，旧包照样越堆越多。现在按「同一变体」判断 —— 重新构建后输出目录里只留最新这一个包，历史包会被清掉。
- 判断依据是文件名末尾的构建时间戳，所以同一次工程的 debug 包与 release 包互不影响，另一个变体的产物不会被误删。

### 说明

- 只删 APK，而且是「新包已经完整写入之后」才清；复制失败时旧包保持原样，不会出现新旧都没了的情况。
- 被别的程序占用、删不掉的旧包只跳过并记一条日志，不会让本次构建失败。
- 不想要这个行为，可以在**设置 → 产物归档**里关掉，历史包会照旧都留着。
