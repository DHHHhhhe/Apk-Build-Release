# 发布说明

## 最新版本

### 本版内容

#### 新增

- **统一输出目录不能设在 Git 仓库里**：以前这只是文档里的一句话，现在保存时直接拒绝，并告诉你「这个目录在哪个仓库里、为什么不行、该换成什么」
  - 为什么值得拦：打出来的 APK 几十到上百 MB，一次 `git add -A` 就会把它们提交进去，进了历史就删不掉
  - 目录还不存在也能判断（从最近的、已经存在的上级目录往上找）

#### 修复

- **设置里的「选择…」与「保存」不再被输入框挤成两行字**：按钮被压到 55px 宽，文字只能折成两行；现在按钮保持自己的宽度，输入框负责让空间
- 统一输出目录改存**绝对路径**：以前存你输入的原样字符串，填相对路径时会跟着进程的工作目录漂，构建时落到哪儿是不确定的

### 安装

下载 `apk-batch-build-<版本>-setup.exe` 装上（安装路径可以自己选），
或者用 `apk-batch-build-<版本>-portable.exe` 免安装直接运行。

装完之后的版本更新由应用自己完成；便携版要换新版本仍需重新下载。

第一次打开会被 Windows SmartScreen 拦一下：没有代码签名证书，发布者显示「未知发布者」。
点「更多信息」→「仍要运行」即可，不是文件损坏（自动更新下来的新版本同样会被拦一次）。

### 运行要求

- Windows
- 本机已装 JDK（AGP 8.x 需要 17）与 Android SDK
- 工具复用你项目本来就能用的那套构建环境，不自己下载工具链
- 除检查更新外，工具不联网、不上传任何数据

### 已知限制

- 只支持本地目录的项目，不能填 Git 地址
- 只标注签名状态，不代签 APK
- 便携版不支持自动更新，换版本要重新下载
- 没有代码签名证书，每次更新都会过一遍 SmartScreen
- 界面单次构建日志最多留 20 万字符、渲染 2000 行
