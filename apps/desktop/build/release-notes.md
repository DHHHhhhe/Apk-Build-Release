# 发布说明

### 本版内容

#### 新增

- **更新完成后会告诉你一句「已更新到 v0.5.1」**：静默安装那几十秒应用是关着的、看不到任何界面，重开时要让用户知道刚才那下成了
  - 会注明上一版是哪个版本；如果是从还不认识版本记录的旧版升上来，说不清从哪一版来就不带那句
  - 首次安装**不提示** —— 那不是「更新」，平白弹一句会让人以为刚出了什么事
  - 这条提示取一次就没了，同一版反复启动不会每次都说
- **更新记录分页了**：一页 5 个版本，底部显示「第几个到第几个 / 共几个」与页码
  - 打开时自动定位到**当前运行的版本**那一页，不用自己翻
  - 翻页后回到列表顶部，不会停在新一页的中间

#### 说明

- 通知条是纯告知，所以 7 秒后自动消失，但 hover、键盘聚焦或窗口不可见时**暂停计时** —— 正在读的时候不该消失
- 它有显式关闭按钮，而且这条信息在「更新记录」里还能再看：不依赖一条会消失的提示
- 尊重系统的「减弱动效」设置：开了之后它不再滑入

上一版（0.5.0）的内容：深色模式；更新入口与设置统一到侧栏左下角。
