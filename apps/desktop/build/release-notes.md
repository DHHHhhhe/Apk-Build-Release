### 修复

- **手动点「检查更新」之后不再什么都不发生**：这一版之前，「已经是最新」与「检查失败」两种结果只在设置弹窗里显示，而设置里的更新区块已经移走了 —— 于是手动检查变成完全静默，用户分不清是「真没有新版本」还是「这功能坏了」。现在这两种结果用右下角一条通知收尾（自动检查仍然保持安静）
- **「已更新到 vX」回到右下角**：上一版为了避开更新提示条把它挪到了右上角，位置与本来的约定不一致。现在两个通知与更新提示条共用一个右下角的叠放容器，同时出现时上下排开、不互相压住

### 变更

- **发布说明文件不再带外层标题**：`build/release-notes.md` 整份就是 Release 正文的原文，而它前面一直挂着「# 发布说明」「### 本版内容」两行 —— 于是 v0.5.0 到 v0.5.3 的 Release 正文都多出这两行。文件已去掉外壳，同步脚本也会直接拒绝带壳的文件，那四版的正文已改正

### 说明

- 更新相关的东西现在只有两处：侧栏左下角（入口与状态）与右下角的叠放区（提示条与通知），设置弹窗里没有任何更新相关的内容
