# 发布说明

## 最新版本

### 本版内容

- 更新检查的结果会写进应用日志：「已是最新版本」/「发现新版本」/「检查更新失败（附原因）」—— 以前这三种情况在日志里长得一样，排查只能靠猜

上一版（0.3.0）的内容：

- **安装版支持自动更新**：启动 15 秒后自动查一次 GitHub Releases，发现新版本时顶栏出现「有新版本」，点开设置可以看更新内容、下载、重启并安装
  - 只提示不静默安装：下载与否由你点
  - 便携版没有安装目录，装更新只会多出一份副本，所以它**不参与自动更新**，仍按老办法换包
  - 关机时不会装更新（避免装到一半被系统掐掉，留下卸载了却没装上的残局）
- **抽屉不再遮挡主列的按钮**：窗口够宽时主列整列让开（滚动条也跟着让开），不够宽时才改为覆盖
  - 抽屉宽度随窗口缩放（420~560px），比上一版更宽，构建记录的日志看得更清楚
- **入队时显式带上变体**：界面显示什么就构建什么，从「时序上凑巧一致」变成结构上保证
  - 两处「全选」的语义也统一了：都是并集，不会把看不见的勾选悄悄抹掉
- 无障碍：勾选计数会播报；抽屉内各区块的标题层级修正

### 安装

下载 `apk-batch-build-<版本>-setup.exe` 装上（安装路径可以自己选），
或者用 `apk-batch-build-<版本>-portable.exe` 免安装直接运行。

装完之后的版本更新由应用自己完成；便携版要换新版本仍需重新下载。

第一次打开会被 Windows SmartScreen 拦一下：没有代码签名证书，发布者显示「未知发布者」。
点「更多信息」→「仍要运行」即可，不是文件损坏（自动更新下来的新版本同样会被拦一次）。

### 运行要求

- Windows
- 本机已装 JDK（AGP 8.x 需要 17）与 Android SDK
- 工具复用你项目本来就能用的那套构建环境，不自己下载工具链
- 除检查更新外，工具不联网、不上传任何数据

### 已知限制

- 只支持本地目录的项目，不能填 Git 地址
- 只标注签名状态，不代签 APK
- 便携版不支持自动更新，换版本要重新下载
- 没有代码签名证书，每次更新都会过一遍 SmartScreen
- 界面单次构建日志最多留 20 万字符、渲染 2000 行
