# 发布说明

### 本版内容

#### 修复

- **设置里不该再有更新的东西**：上一版把更新入口搬到了左下角，但设置弹窗里还留着一整套「版本与更新」区块（当前版本、下载、检查、更新记录）——同一个功能两个入口，两边状态还可能不一致。现在设置里只剩「统一输出目录」与「构建日志」
- **更新记录的重开与连点**：对话框每次打开都会重新定位到当前运行版本那一页（原来只在第一次挂载时算，关掉再开还停在旧页）；连点「下一页」也不会只前进一步了

#### 变更

- **更新记录的显示按参考实现的样式重做**：版本号带 `v` 前缀并配日期，当前运行的那版右侧挂「当前版本」标签；分类改成带图标的小标签（新增绿、优化蓝、修复黄、说明灰，认不出的退回中性样式）；条目改成圆点 + 纯文本，正文里不再出现 markdown 标记

#### 说明

- 每版之间用一条分隔线分开，滚动区收在 52vh —— 窗口最小能缩到 680px，再高一点标题栏与翻页条会被挤出可视区
- 只有一页时不显示翻页条：摆两个永远点不动的按钮没有意义
