### 新增

- **只重跑失败的变体**：多个渠道里挂掉一个时，不用把已经成功的那些重打一遍。队列项上给「重试失败变体」，队列头还能一次重试所有失败项（每个失败项也只补它自己失败的那几个）
- **关掉再打开，排队中没跑的项还在**：以前重启会把「排队中」和「构建中」一起标成失败，等于把排好的队白排了。现在只收尾真的在跑的那一项，剩下的留着，界面上给一个「继续上次队列」由你决定什么时候接着跑
- **构建中关窗会先问一句**：说明会中断几项。以前关窗直接退出并杀掉正在跑的构建，跑掉的那几分钟白费，而且不会自动续跑
- **入队前先做一次快速检查**：缺 gradlew、项目目录没了、输出目录找不到这类问题，在勾选表上直接标出来 —— 只提示，不拦你入队。它只查文件，不启动 Java，所以是毫秒级的
- **产物归档目录里多一份 manifest**：记录每个变体最新的那个包是哪一个。同名产物仍然只加时间戳、不覆盖，但以后不用在一堆历史包里认文件名了
- **勾选表与侧栏直接显示归档文件夹名**：别名决定产物落到哪个文件夹，以前要打开项目面板才看得到；多个项目用同一个归档名时还会标出冲突，免得两边的包混进同一个目录
- **变体按渠道分组**：多渠道项目现在按 flavor 分组，每组给一个「只选本渠道」，不用再逐个勾
- **队列项列出每个失败变体的原因**：以前只显示第一条，一个项目挂两个变体时，第二个为什么挂得自己翻日志
- **汇总每行显示应用包名与版本号**，交付前核对版本不用再逐个翻构建记录
- **「复制清单」替代了原来的「复制路径」**：复制出来是可直接粘进表格的多列清单（项目、变体、状态、文件名、大小、签名、包名、版本、完成时间、路径）
- **汇总支持筛选**：按关键字（变体、文件名、项目名）和状态过滤
- **拖拽项目文件夹时整窗都有反馈**：以前只有空状态那张引导卡会变，已经有项目时拖进来毫无反应；一次拖多个也会说明只加了第一个
- **出包后能直接去拿包**：队列成功项和汇总每一行都多了「打开产物目录」
- **构建记录可以点选**：日志区不再固定看默认那一条，点任意一条变体就能看它的日志
- **构建完成的通知可以点**：点一下窗口回到前台
- **任务栏显示队列进度**：跑完或清空后自动消失
- **「全部取消」会先确认**：并说明会中断几项 —— 取消正在跑的构建代价不低，不该一点就没
- **别名下方显示产物会归档到哪**：改完别名能立刻看到落点，保存后还有一次「已保存」的确认

### 修复

- **「日志文件」按钮点了没反应**：它把日志文件路径交给了只该处理目录的打开逻辑，对已存在的文件会先尝试建目录并直接失败，而失败又被丢掉了。现在文件和目录分开处理，失败也会弹出可见的提示
- **窄窗口下项目面板盖住主列的操作**：窗口被拖窄时，勾选表右侧那排「全选 / 清空 / 只选 release」和队列的取消、清空按钮会被面板压住，表现是点了没反应。现在面板宽度会按窗口与侧栏的实际宽度算，放不下时把动作整行换到左边
- **点「查看日志」不再只打开面板**：以前打开后停在变体列表，日志在首屏之外，还得自己往下滚。现在会滚到日志区并高亮一下
- **历史构建的日志不再显示「（还没有输出）」**：重启后回看旧记录时，那句话看起来像构建真的没有输出。现在会说明是历史记录，并给出「打开日志文件」
- **清空队列前会确认**：以前「清空已结束」「清空全部」直接执行，而且会连带删掉这些队列项对应的构建记录 —— 现在先说清会删多少条、删什么（产物文件不删）
- **设置里改了输出目录不保存就关闭，不再静默丢失**：会出现「有未保存的改动」，关闭前也会拦一道
- **右下角两条提示不再互相压住**：更新提示条与系统通知以前是两个独立的浮层，同时出现时叠在一起
- **Esc 不再清空勾选**：以前在勾选表里按 Esc 会把一整批勾选清掉并立即写库，与「Esc = 关闭/取消」的习惯相反；清空仍然有按钮
- **多个错误不再叠成一片**：几处错误以前各占一条红条，现在合并成一条，其余只报数量，看过了可以关掉
- **打开目录或文件失败时不再静默**：以前失败什么都不显示，看起来像按钮坏了
- **构建中心的视图与折叠状态会记住**：切到「已构建的」再切回来，折叠过的项目不会又全展开
- **一个项目在解析变体时不再锁住整张勾选表**：只禁用那个项目自己的那一行

### 变更

- **「最近一批」现在按一次入队算**：一次勾选多个项目会为每个项目建一条队列项，而汇总以前只取最后跑完的那一个 —— 勾 5 个项目跑完只看到 1 个，和界面上写的「这一批」不符。现在这一批的产物会一起出现（升级前入的队仍按原样显示）
- **两个构建入口的文案统一了**：顶栏那个改为「构建当前项目（N）」，勾选表底部仍是「构建勾选项（N）」；没打开项目面板时不再显示一个点不动的灰按钮，禁用原因也不再只藏在悬停提示里
- **并发上限从动作区移到信息区**：它是设置不是动作，和「取消 / 清空」并排容易被误点，现在跟标题与计数放一起，并说明改完立即生效、正在跑的不会被打断
- **主题档位与开关的点击范围放大**：原来偏小，不好点
- **侧栏的上移/下移按钮改为悬停或键盘聚焦时才出现**：每行都挂两个箭头太吵
- **项目没有 release 变体时会把话说清**：列表会说明「下面列的是全部变体」，并标出「不能上架」——以前 debug 变体既不显示类型也没有提示，包打出来才知道

### 说明

- 归档仍然不会覆盖同名产物：新增的 manifest 只是记下每个变体最新的那一份，旧包都留着
- 关窗确认用的是系统对话框，所以它会出现在窗口之外的最上层，也不会被界面样式影响
- 入队前的检查只覆盖「一眼能看出缺东西」的几种；完整的环境探测（会真的启动 Java）仍然在项目详情里手动触发
