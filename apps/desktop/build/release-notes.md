# 发布说明

## 最新版本

### 本版内容

- **变体列表里不再重复恒定的标签**：整个列表都是 `release` 时，逐行再标一遍 `release` 只是噪音 —— 现在只在标签真能起区分作用时才显示：多个 flavor 才显示 flavor，buildType 不统一才显示 buildType
- **去掉「只选 release」按钮**：列表里只有一种 buildType 时它等于全选，是个恒等操作；现在只在真有多种类型时才出现
- 构建中心与项目详情两处用的是同一条判断（`lib/variant-badges.ts`），不会再一边有一边没有

上一版（0.3.1 / 0.3.2）的内容：更新检查的结果写进应用日志 ——「已是最新版本」/「发现新版本」/「检查更新失败（附原因）」。0.3.0 的内容：安装版支持自动更新、抽屉不再遮挡主列、入队时显式带上变体。

### 安装

下载 `apk-batch-build-<版本>-setup.exe` 装上（安装路径可以自己选），
或者用 `apk-batch-build-<版本>-portable.exe` 免安装直接运行。

装完之后的版本更新由应用自己完成；便携版要换新版本仍需重新下载。

第一次打开会被 Windows SmartScreen 拦一下：没有代码签名证书，发布者显示「未知发布者」。
点「更多信息」→「仍要运行」即可，不是文件损坏（自动更新下来的新版本同样会被拦一次）。

### 运行要求

- Windows
- 本机已装 JDK（AGP 8.x 需要 17）与 Android SDK
- 工具复用你项目本来就能用的那套构建环境，不自己下载工具链
- 除检查更新外，工具不联网、不上传任何数据

### 已知限制

- 只支持本地目录的项目，不能填 Git 地址
- 只标注签名状态，不代签 APK
- 便携版不支持自动更新，换版本要重新下载
- 没有代码签名证书，每次更新都会过一遍 SmartScreen
- 界面单次构建日志最多留 20 万字符、渲染 2000 行
