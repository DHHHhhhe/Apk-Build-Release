### 变更

- **输出目录改成「本次构建的镜像」**：开着设置里的「新增 APK 覆盖原有包体」时，每次构建完成后会清空该项目的输出目录，只留本次产出的包 —— 历史 APK、子文件夹（比如多渠道打包的「渠道包」目录）、其他普通文件都会被清掉，不用再手动收拾。

### 说明

- 同一次构建里产出的多个包会一起保留，比如同时构建 debug 与 release，两个都在；下次只构建其中一个时，另一个的旧包会作为历史内容清掉。
- 清理是在新包完整写入之后才做的，复制失败时旧内容保持原样。
- 被别的程序占用、删不掉的项只跳过并记一条日志，不会让构建失败。
- 想保留历史包，在**设置 → 产物归档**里把开关关掉即可。
- 这个行为不可逆，别把需要长期留存的文件放在项目的输出目录里。
