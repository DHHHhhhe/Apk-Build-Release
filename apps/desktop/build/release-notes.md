## 最新版本

### 本版内容

- **界面重构：全局与项目分层**。主内容列只放全局内容（构建中心 + 队列），项目级内容收进右侧抽屉
  - 点左侧项目打开抽屉：变体选择、变体来源与限制、构建环境自检、该项目的构建记录
  - 抽屉是**非模态**的：开着的时候主列照样能勾选、能入队；`Esc` 关闭，关闭后焦点回到刚才那个项目
  - 没打开项目时，主列就是干净的全局工作台，不再出现「某个项目的详情」
- **不再出现 release / debug 的说明文字**：工具只出 release 包，这既是规则也是事实，界面上不再解释它，也不再提供「显示 debug 变体」的开关
- 构建中心：在一处看到所有项目的可构建变体，勾好一次入队
  - 两个视图：「要构建的」（跨项目勾选表）与「已构建的」（这批产物的汇总）
  - 已在队列中的项目自动跳过并说明跳过了几个；无变体的项目给出原因与「用 Gradle 解析」入口
- 多项目批量出包：一次登记多个本地项目，按队列跑完，一条失败不影响后面的
- 变体列表来自项目自身：静态解析 Gradle 配置，解析不可信时回退跑 Gradle
- 产物集中收集到统一目录，按项目分子目录，保留原文件名
- 失败分类：OOM、缺 SDK 组件、JDK 版本不符、超时等分开给建议
- 取消会杀掉整棵 Gradle 进程树，不留孤儿 java.exe
- 构建完成系统通知

### 安装

下载 `apk-batch-build-<版本>-setup.exe` 装上（安装路径可以自己选），
或者用 `apk-batch-build-<版本>-portable.exe` 免安装直接运行。

第一次打开会被 Windows SmartScreen 拦一下：没有代码签名证书，发布者显示「未知发布者」。
点「更多信息」→「仍要运行」即可，不是文件损坏。

### 运行要求

- Windows
- 本机已装 JDK（AGP 8.x 需要 17）与 Android SDK
- 工具复用你项目本来就能用的那套构建环境，不自己下载工具链
- 工具本身不联网、不上传任何数据

### 已知限制

- 只支持本地目录的项目，不能填 Git 地址
- 只标注签名状态，不代签 APK
- 不带自动更新，新版本需要手动换包
- 界面单次构建日志最多留 20 万字符、渲染 2000 行
