# 发布说明

### 本版内容

#### 新增

- **深色模式**：侧栏左下角可以选「跟随系统 / 浅色 / 深色」三档
  - 跟着系统走时会随系统的明暗自动切换
  - 窗口底色、滚动条、右键菜单一起变；启动时不会先闪一帧浅色
- **更新相关的入口都搬到侧栏左下角了**：自动检查开关、检查更新、更新记录
  - **版本号可以点开**，看历次版本改了什么 —— 这份记录打进了包里，**断网也能看**
  - 更新记录里每类改动带图标与语义色（新增绿、优化蓝、修复黄、说明灰），一屏里扫得出来哪几类是重点
  - 「自动检查更新」关掉只是不在启动时自动查，手动点照旧工作；已经下好的更新也照旧提示安装
  - 左下角统一成「左边是信息、右边是能点的控件」，不用逐个 hover 去猜哪个能点

#### 说明

- 设置入口从顶栏移到左下角
- 深色令牌本来就是设计规范里定好的那一套（D11），这次只是把它接上线，配色值一个字没改
- 深色下卡片比画布亮、侧栏与卡片同色，和浅色下的层次关系保持一致
