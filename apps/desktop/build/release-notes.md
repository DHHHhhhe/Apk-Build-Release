# 发布说明

### 本版内容

#### 新增

- **发现新版本时右下角浮出提示条**，把「这版改了什么」直接摆出来，下不下由你点
  - 更新内容按分类拆开显示，分类用小标签上色：新增绿、修复橙、其余蓝；认不出的分类原样显示，不丢内容
  - 两个动作：**「下载并更新」**与**「稍后」**
  - 点「稍后」只是收起这一条，主进程的状态不动 —— 左下角的那个按钮会跟着变成「下载 x.y.z」，从那里接着走
  - 下载中显示进度条；下载完变成**「立即重启并更新」**与「稍后」，并提示「也可以先接着用，下次关窗口时会自己装上」
- 「已经是最新」「检查失败」这两种「什么都没发生」的结果**不占位置**：只有你自己点过「检查更新」之后才用一句提示收尾

#### 变更

- **设置入口换个位置**：不再单占一行带文字标签（那样和上面的「主题」「自动检查更新」不成一路），改成版本号那一行右侧的小齿轮，和「检查更新」并排
- 「已更新到 vX」的提示条挪到右上角 —— 右下角留给更新提示条，两者可能同时出现

#### 说明

- 更新提示条浮在角落而不是插进内容流：更新是异步事件，而用户多半正在出包流程里，摆在内容流里会把「构建中心」往下顶，而这件事并不需要立即处理
- 有构建任务在跑时，「立即重启并更新」是禁用的（重启会把那一单掐断）
